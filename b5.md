# Bài 5: Thiết kế và Cấu hình dịch vụ Systemd Service cho ứng dụng Java

## 1. Tạo tài khoản hệ thống `java-runner`

```bash
sudo useradd -r -s /usr/sbin/nologin java-runner
```

**Giải thích các tham số:**
- `-r`: Tạo system account (UID thấp, không có home directory mặc định) — phù hợp cho tài khoản chạy dịch vụ.
- `-s /usr/sbin/nologin`: Gán shell là `nologin`, ngăn tài khoản này đăng nhập trực tiếp vào hệ thống — tăng cường bảo mật.

**Xác nhận tài khoản đã tạo:**
```bash
id java-runner
```
```
uid=998(java-runner) gid=998(java-runner) groups=998(java-runner)
```

---

## 2. Tạo file cấu hình dịch vụ Systemd

```bash
sudo nano /etc/systemd/system/java-app.service
```

### Nội dung file `java-app.service`

```ini
[Unit]
Description=Java Spring Boot Application Service
Documentation=https://docs.spring.io
After=network.target
Wants=network-online.target

[Service]
Type=simple
User=java-runner
Group=java-runner

# Lệnh khởi chạy ứng dụng
# Môi trường thật: ExecStart=/usr/bin/java -jar /opt/java-app/app.jar
# Môi trường mô phỏng (giả lập tiến trình chạy dài):
ExecStart=/usr/bin/sleep 1000

# Thư mục làm việc
WorkingDirectory=/opt/java-app

# Cấu hình tự động restart
Restart=on-failure
RestartSec=10s

# Giới hạn tài nguyên (tùy chọn, tăng bảo mật)
NoNewPrivileges=true
PrivateTmp=true

# Ghi log ra stdout/stderr để journald thu thập
StandardOutput=journal
StandardError=journal
SyslogIdentifier=java-app

[Install]
WantedBy=multi-user.target
```

---

## 3. Tạo thư mục làm việc và phân quyền

```bash
sudo mkdir -p /opt/java-app
sudo chown java-runner:java-runner /opt/java-app
```

> Trong thực tế, file JAR ứng dụng sẽ được đặt tại `/opt/java-app/app.jar`.

---

## 4. Nạp cấu hình và khởi động dịch vụ

```bash
# Nạp lại cấu hình systemd sau khi tạo/sửa file service
sudo systemctl daemon-reload

# Khởi động dịch vụ
sudo systemctl start java-app.service

# Bật tự khởi động khi boot máy
sudo systemctl enable java-app.service
```

**Kết quả `enable`:**
```
Created symlink /etc/systemd/system/multi-user.target.wants/java-app.service
→ /etc/systemd/system/java-app.service.
```

## 7. Kiểm tra chính sách tự động restart

Mô phỏng tiến trình bị sập bất thường:

```bash
# Lấy PID của tiến trình
sudo systemctl status java-app.service | grep "Main PID"
# Main PID: 4521

# Buộc kill tiến trình bằng SIGKILL (mô phỏng crash)
sudo kill -9 4521
```

**Quan sát systemd tự restart sau 10 giây:**

```bash
sudo systemctl status java-app.service
```

```
● java-app.service - Java Spring Boot Application Service
     Loaded: loaded (/etc/systemd/system/java-app.service; enabled)
     Active: activating (auto-restart) (Result: signal) since Tue 2026-10-06 10:31:02 UTC; 3s ago

Oct 06 10:31:02 server systemd[1]: java-app.service: Main process exited, code=killed, status=9/KILL
Oct 06 10:31:02 server systemd[1]: java-app.service: Failed with result 'signal'.
```

*Sau 10 giây (`RestartSec=10s`):*

```
● java-app.service - Java Spring Boot Application Service
     Active: active (running) since Tue 2026-10-06 10:31:12 UTC; 2s ago
   Main PID: 4598 (sleep)

Oct 06 10:31:12 server systemd[1]: java-app.service: Scheduled restart job, restart counter is at 1.
Oct 06 10:31:12 server systemd[1]: Started Java Spring Boot Application Service.
```

> Systemd đã tự động khởi động lại dịch vụ với PID mới `4598` sau đúng 10 giây — xác nhận `Restart=on-failure` hoạt động đúng.

## 8. Các lệnh quản lý dịch vụ thường dùng

```bash
# Dừng dịch vụ
sudo systemctl stop java-app.service

# Khởi động lại dịch vụ
sudo systemctl restart java-app.service

# Tải lại cấu hình không restart (nếu app hỗ trợ SIGHUP)
sudo systemctl reload java-app.service

# Tắt tự khởi động khi boot
sudo systemctl disable java-app.service

# Xem log realtime
journalctl -u java-app.service -f
```

---

## 9. Giải thích cấu trúc file `.service`

| Directive | Giá trị | Ý nghĩa |
|---|---|---|
| `After=network.target` | — | Đảm bảo dịch vụ khởi động sau khi mạng sẵn sàng |
| `User=java-runner` | java-runner | Chạy tiến trình dưới quyền user giới hạn, không phải root |
| `Restart=on-failure` | on-failure | Chỉ restart khi tiến trình thoát do lỗi (exit code ≠ 0 hoặc bị kill) |
| `RestartSec=10s` | 10 giây | Thời gian chờ trước khi restart |
| `NoNewPrivileges=true` | — | Ngăn tiến trình leo thang đặc quyền |
| `PrivateTmp=true` | — | Cấp `/tmp` riêng cho dịch vụ, cô lập với hệ thống |
| `WantedBy=multi-user.target` | — | Kích hoạt dịch vụ ở chế độ multi-user (server mode) |

---

## 10. Tóm tắt các lệnh đã thực hiện

```bash
# 1. Tạo system user
sudo useradd -r -s /usr/sbin/nologin java-runner

# 2. Tạo thư mục ứng dụng
sudo mkdir -p /opt/java-app
sudo chown java-runner:java-runner /opt/java-app

# 3. Tạo file service
sudo nano /etc/systemd/system/java-app.service

# 4. Nạp lại cấu hình
sudo systemctl daemon-reload

# 5. Khởi động và bật autostart
sudo systemctl start java-app.service
sudo systemctl enable java-app.service

# 6. Kiểm tra trạng thái
sudo systemctl status java-app.service
journalctl -u java-app.service -n 20 --no-pager
```
